# 📈 Инвестор Портфель — Telegram Бот

Telegram-бот для управления инвестиционными портфелями криптовалют с отслеживанием прибыли и убытков.

## Возможности

- **Управление портфелями** — создание, просмотр и удаление портфелей
- **Добавление активов** — с указанием цены покупки, количества и даты
  - Автоматическое определение даты покупки по цене через CoinGecko API
- **Продажа активов** — фиксация продаж с ценой, количеством и датой
- **Удаление активов** — полное удаление актива из портфеля
- **Статистика (Профит/Убыток):**
  - Сводка по всем портфелям
  - Детальная таблица по каждому активу
  - Реализованный и нереализованный P&L
  - Процент роста/падения
- **Интеграция CoinGecko API** — текущие цены в реальном времени
- **Интерфейс на русском языке** с кнопками `ReplyKeyboardMarkup` под полем ввода

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
export TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
python bot.py
```

## Структура данных

Данные портфелей хранятся в `portfolios.json` в формате:

```json
{
  "user_id": {
    "Название портфеля": {
      "assets": {
        "btc": {
          "coin_id": "bitcoin",
          "symbol": "BTC",
          "entries": [
            {"price": 65000, "amount": 0.5, "date": "01.01.2025"}
          ],
          "sells": [
            {"price": 70000, "amount": 0.1, "date": "15.03.2025"}
          ]
        }
      },
      "created": "01.01.2025 12:00"
    }
  }
}
```

## Технологии

- Python 3.11+
- [python-telegram-bot](https://python-telegram-bot.org/) v21
- [CoinGecko API](https://www.coingecko.com/en/api) (бесплатный)
- ReplyKeyboardMarkup (кнопки под полем ввода, не inline)
